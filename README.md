# TaskFlow01

Sistema de gerenciamento de tarefas desenvolvido em React + Vite para a disciplina da faculdade.

O aplicativo permite cadastrar, visualizar e excluir tarefas, além de salvar os dados no navegador utilizando localStorage.

---

# Funcionalidades

✅ Menu de navegação entre páginas  
✅ Cadastro de tarefas  
✅ Listagem dinâmica de tarefas  
✅ Exclusão de tarefas  
✅ Persistência de dados com localStorage  
✅ Formulários controlados com useState  
✅ Componentes reutilizáveis em arquivos separados  
✅ Interface utilizando Bootstrap  

---

# Tecnologias utilizadas

- React
- Vite
- JavaScript
- Bootstrap
- React Router DOM
